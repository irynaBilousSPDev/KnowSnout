# KnowSnout — структура продукту (UA/PL ринки)

Код і назви полів БД: **англійською**.
Інтерфейс користувача: **українська** першою (польська пізніше через ті ж i18n-ключі).
Це **не ламає** базу даних.

---

## 1. Візія
Один застосунок для догляду за тваринами вдома і в подорожі: довіра до корму, профілі тварин, медичні документи, поради з гри — починаючи з **собак і котів**, потім інші популярні тварини.

Ринки v1: **Україна + Польща**.

### F. Довідники та довіра (новий модуль — на основі аналізу community-чатів)
Об'єднаний довідник надійних контактів і сервісів навколо тварини — одна точка пошуку замість розкиданих Instagram/Facebook/Telegram джерел.

| Категорія | Що включає | Ключові потреби з дослідження спільноти |
|--|--|--|
| Ветеринари | Клініки + вузькі спеціалісти (стоматолог, офтальмолог, невролог, поведінковий) | Фільтр за спеціалізацією та мовою лікаря (укр/пол/англ) — найчастіший запит спільноти |
| Лабораторії | Аналізи, тести на титри антитіл — окремо від клінік | Користувачі розрізняють клініку і лабораторію (напр. Vetlab, Labwet) |
| Заводчики | Профілі з верифікацією родоводу (FCI) | Попередження про псевдозаводчиків, "намальовані" родоводи |
| Перевізники тварин | Для перетину кордону | Відгуки + попередження про шахрайство/"домовленості за гроші" |
| Петсіттери / грумери / кінологи | Картки з локацією, мовою, відгуками | Community активно ділиться контактами в Instagram/Facebook — варто консолідувати |
| Страхування тварин | Порівняння пакетів (напр. PetHelp, PZU) | Попит на порівняння умов і відгуки власників |
| Житло, що приймає тварин | Поради + позначка pet-friendly | Відмови власників, подвійна кауція — гостра емоційна тема |
| Донорство крові / community-допомога | Заклики про донорів-тварин | Менший пріоритет, соціальна фіча |

Єдина модель для всього модуля: один пошук, спільні фільтри (місто, мова, вид тварини), одна система відгуків/рейтингів (перевикористовує модель з модуля E). Дані наповнюються вручну спочатку (curated), community-верифікація — пізніше.

**План верифікації (v1 → v2):**

| Рівень | Значення бейджа | Хто підтверджує | v |
|--|--|--|--|
| Не позначено | Запис додано, ще не перевірявся | — | v1 |
| "Не підтверджено" (сірий чіп) | Community додала запис, дані з відкритих джерел (сайт, Google Maps) | Автоматично при імпорті | v1 |
| ✓ "Перевірено" (зелений бейдж) | Команда KnowSnout зв'язалась із закладом і підтвердила контакти/послуги/мову | Curator-модератор вручну, разова перевірка | v1 |
| ✓ "Перевірено" + дата | Те саме, з датою останньої перевірки (для протермінованих — знову сірий) | Модератор, повторна перевірка раз на 6-12 міс | v2 |
| ⚠ "Скарги" (жовтий чіп) | 2+ підтверджені скарги від різних користувачів за останні 6 міс | Модерація скарг вручну перед публікацією | v1 |

**Правила модерації:**
- Скарга публікується на картці закладу тільки після ручної перевірки модератором (уникнути неправдивих звинувачень і юридичних ризиків — див. розділ 3).
- Заклад з активною перевіркою шахрайства позначається одразу, ще до завершення розгляду, але формулюванням "На розгляді" — не звинуваченням.
- Заводчики: бейдж "✓ FCI" видається тільки після перегляду фото/сканів родоводу модератором; без документів — "Не підтверджено", без прихованого дефолту "перевірено".
- Джерело даних (curated / community / офіційне API) завжди видиме користувачу — наприклад підпис "Дані: Google Maps" чи "Підтверджено KnowSnout, 07.2026" під контактами.

**Наповнення v1:** ручний curated список 20-30 закладів на старт (Варшава + 1-2 українських міста), сфокусований на категоріях з найсильнішим сигналом — ветеринари й заводчики. Community зможе пропонувати нові записи через форму "Додати заклад" (модерація перед публікацією).

**План контент-наповнення:**

| Джерело | Що дає | Формат | Коли |
|--|--|--|--|
| Ручний збір командою з дослідження community-чатів | Перші 20-30 закладів (клініки, лабораторії, заводчики, петсіттери — імена й посилання вже зібрані в Додатку п.5а) | Таблиця → імпорт у БД (назва, категорія, місто, мова, контакт, джерело) | Перед запуском v1 |
| Google Maps / Google Places API | Адреса, години роботи, телефон, фотографії закладу — там де назва вже відома | Автоматичний lookup за назвою при додаванні запису | v1 (економить ручний ввід) |
| Форма "Додати заклад" (у застосунку) | Community поповнює довідник органічно — власники приводять "своїх" перевірених спеціалістів | Заявка → черга модерації → публікація зі статусом "Не підтверджено" | v1, паралельно з ручним збором |
| Офіційні реєстри (де є) | Заводчики з реальною метрикою FCI, ветеринарні палати (список ліцензованих лікарів) | Звірка вручну модератором під час підтвердження бейджа | v1 для бейджа "✓ FCI" / "✓ Перевірено" |
| Партнерські угоди (страхування, перевізники) | Офіційні тарифи/умови напряму від партнера, а не зі скрейпінгу | API/фід від партнера | v2, збігається з монетизацією (afiliate) |

**Хто відповідає:** на старті — сам засновник/невелика команда (ручна модерація low-volume). Формалізований процес модерації (SLA на розгляд заявки, ролі) — коли черга "Додати заклад" перевищить ручну пропускну здатність.

**Оновлення даних:** контакти застарівають — картка закладу показує дату останньої перевірки; заклади без оновлення понад 12 міс автоматично втрачають бейдж "✓ Перевірено" (падають до "Потребує повторної перевірки"), не видаляються.

**Пов'язані, але нижчого пріоритету інсайти з дослідження (тримати в бек-лозі, не будувати зараз):**
- Community-цінник ("скільки коштувала операція X") — розширення відгуків у модулі E, не окремий модуль
- Довідник аптек/зоомагазинів з наявністю конкретних препаратів — нішево, не будувати v1
- Маркетплейс обміну речами (переноски, амуніція) — розмиває фокус, вже покрито OLX/групами
- Пряме поглиблення "чи користуються трекером щеплень" — підтверджує пріоритет вже наявного модуля C, не нова фіча

## 3. Юридичні примітки / примітки довіри
- **Мікрочип:** ОК зберігати як **приватну** нотатку власника (як номер паспорта в гаманці). НЕ будувати публічний пошук чипів. Дотримуватись GDPR/UA приватності.
- **Вакцини / прикордонні правила:** завжди "інформація на основі офіційних гайдів, звіряйтесь з ветеринаром / перевізником".
- **AI визначення породи:** показувати рівень впевненості; мікси — звичайна справа; без медичних тверджень.
- **Зовнішні рейтинги:** пріоритет офіційним API/партнерам; уникати скрейпінгу захищених ToS відгуків.
- **Довідники (модуль F):** позначати статус верифікації запису (curated / community-confirmed / unverified); не публікувати непідтверджені звинувачення в шахрайстві без модерації.

## 5a. Додаток: інсайти з дослідження community-чату (Варшава, тема "Pets", 09.2024–08.2026)

Розширений розбір реальних запитів спільноти — джерело для пріоритизації модуля F.

**Ветеринарна допомога та вузькі спеціалісти** — найчастіша категорія запитів за весь час: стоматолог, офтальмолог, невролог для старих тварин, поведінковий ветеринар, грумер для чищення залоз у котів. Постійні прохання саме про україномовного/російськомовного/англомовного лікаря.

**Прозорість цін і реального досвіду лікування** — регулярні питання "скільки коштувала операція/аналізи/видалення зубів" (приклад: видалення всіх зубів коту — близько 2000 zł без аналізів). Community-цінник чи калькулятор орієнтовної вартості.

**Гід-чеклист міжнародних подорожей** — найскладніша й найсуперечливіша тема: паспорт ЄС, чіп, вакцина від сказу, тест на титри антитіл (очікування ~4 місяці), форма Ф1/сертифікат здоров'я, різні вікна (21/30 днів, 3-4 місяці), різні вимоги на різних КПП (Угринів, Рава-Руська, Устилуг). Відповіді спільноти часто суперечливі — сигнал для інтерактивного чеклиста з нагадуваннями про дедлайни, а не просто статичного списку.

**Реєстр перевірених перевізників тварин** — відгуки, попередження про шахрайство і "домовленості за гроші" на кордоні.

**Реєстр перевірених заводчиків/розплідників** — верифікація родоводу (FCI), попередження про псевдозаводчиків ("родовід можна намалювати"), критика умов у частині розплідників ("плодильні" без вигулу). Пошук не тільки у Варшаві.

**Маркетплейс петсіттерів і кінологів** — конкурентний застосунок Petsy згадувався кілька разів як робоче рішення; попит на офлайн-заняття з кінологом (Варшава, Краків, Вроцлав) і дискусія онлайн/офлайн.

**Pet-friendly житло** — одна з найгостріших емоційних тем: відмови власників (за оцінками спільноти 30-40%), подвійна кауція, доплата ~100 zł/міс за тварину, рекомендаційні листи про "вихованість". Потенціал для розділу порад + фільтра pet-friendly.

**Страхування тварин** — відгуки й порівняння пакетів (PetHelp, PZU).

**Донорство крові для тварин** — community організовує пошук котів-донорів (вимоги: вага, вік) — можливий модуль community-допомоги.

**Обмін/передача речей** (переноски, амуніція для притулків) — потенціал міні-дошки оголошень, нижчий пріоритет.

**Доступність товарів і ліків** — протипаразитарні засоби, ліки, недоступні в Україні, але доступні в Польщі (напр. dexafort) — потенційний довідник "де купити" з позначкою аптека/клініка/зоомагазин.

**Прямий запит на застосунок для здоров'я тварини** — пряме запитання в чаті, чи існує апка для трекінгу вакцинацій і медичної історії — підтверджує пріоритет вже наявного модуля C.

**Побутові поради з безпеки** — небезпека мішури/гірлянди для котів, кабелі під напругою, кілька мисок з водою — формат бази знань/FAQ.

**Етика адопції** — обговорення адопції замість купівлі як подарунка, посилання на групи адопції — узгоджується з роадмапом п.10 (притулки) і п.12 (адопція).

**Окремі лабораторії** (Vetlab, Labwet) — відокремлено від клінік, підтверджує потребу окремої категорії "Лабораторії" в модулі F.

## 7. Навігація

Нижня таб-бар навігація — 5 вкладок: **Стрічка · Перевір · Улюбленці · Спільнота · Довідники**. Модуль F отримує власну вкладку (не схований пункт меню), бо це самостійний, часто використовуваний розділ, а не другорядна службова функція.

Референс патерну — таб-бар на екрані F1 (`KnowSnout - Довідники.dc.html`). Роблю поетапно: спочатку зафіксувати патерн на ключових хаб-екранах кожного модуля, потім поширити на решту екранів зі стрічкою знизу.

## 9. Адмінка — аналіз по всьому застосунку

Модуль F — не єдине місце, де потрібне ручне управління. Розбір по модулях:

| Модуль | Що потребує адмінки | Тип рішення |
|--|--|--|
| A. Харчова аналітика | Модерація власного каталогу `products` (дублікати, помилкові AI-розпізнавання складу), керування кешем AI-відповідей | Content-менеджер |
| B. Улюбленці | Мінімально — дані приватні користувача. Хіба що модерація фото аватарів/альбомів на скарги | Модерація за скаргою |
| C. Здоров'я/документи | Найкритичніше: контент-таблиці правил (вакцинація UA/PL, чек-листи паспорта/подорожей) — вимагають ручного оновлення при зміні законодавства ЄС/UA. Помилка тут = юридичний ризик | Content-менеджер + періодичний ревʼю (напр. раз на квартал) |
| D. Гра/збагачення | Курійований контент порад — рідко оновлюється, низький пріоритет адмінки | Content-менеджер, рідко |
| D2. Безпека рослин | База токсичності рослин — критична точність (як і C). Помилкова відповідь "не токсично" небезпечна для тварини | Content-менеджер, з обов'язковим "vet-reviewed" прапорцем перед публікацією |
| E. Спільнота (пости, форум, блог, квізи) | Модерація постів/тредів/коментарів на скарги, бан користувачів, підтримка авторства блог-статей, вигадування/модерація квіз-питань (дані з Wikidata можуть бути неточні) | Content-менеджер (модерація) + Адміністратор (бан/блок) |
| F. Довідники | Вже описано вище: черга заявок, бейджі, скарги | Content/Trust-менеджер |
| Монетизація | Керування Plus-підписками (ручні рефанди, спірні платежі), afiliate-посилання (перевірка, що ще активні) | Адміністратор |

**Спільна інфраструктура адмінки, потрібна одразу (не лише для F):**
- Єдина черга модерації (скарги/заявки з будь-якого модуля потрапляють в один список, з фільтром за типом)
- Rules/Content CMS для C і D2 — версійований контент (щоб бачити історію змін правил вакцинації чи токсичності рослин, не тільки поточний стан)
- Керування користувачами (бан, перегляд скарг на конкретного користувача) — актуально і для форуму/чату, і для довідників

**Оновлений висновок по ролях:** тих самих двох ролей (Content-менеджер + Адміністратор) вистачає на весь застосунок, не тільки на модуль F — просто черга модерації тепер об'єднує кілька джерел (заклади F, пости/форум E, контент C/D2). Супер-адмін і далі не потрібен на MVP.

## 10. Монетизація (узгоджена з витратами)

- Free: штрихкод + обмежені AI-сканування
- Plus: необмежений AI, тварини, нагадування, пакети для подорожей
- Affiliate: посилання на магазини / іграшки (UA/PL), партнерства зі страхуванням (модуль F)

Витрати на OpenAI контролюються **кешем каталогу + лімітами запитів**.
